# Roles objetivo — búsqueda internacional

> Estado: borrador operativo para el piloto. Se ajustará tras evaluar 10 vacantes reales.

## Perfil de partida

Construir y entregar soluciones completas que combinen automatización, agentes de IA, integraciones API, n8n, Supabase/PostgreSQL, RAG, WhatsApp/CRM e interfaces. El posicionamiento no es competir como especialista puro de React/Node, sino demostrar capacidad de resolver un flujo de negocio de punta a punta.

## Rol A — AI Automation Engineer

**Prioridad:** principal.

**Títulos equivalentes:** AI Automation Engineer, AI Automation Specialist, Automation Engineer, AI Integration Engineer, AI Solutions Engineer, Intelligent Automation Engineer.

**Problema que resuelve:** procesos manuales, desconectados o lentos que pueden orquestarse mediante APIs, agentes, bases de datos, CRM y canales de mensajería.

**Señales de buen encaje:**

- Automatización de operaciones, ventas, soporte, onboarding o knowledge management.
- n8n, Make, Zapier, APIs, webhooks, LLMs, RAG, Postgres/Supabase o CRM.
- Responsabilidad de diseñar, construir, depurar y explicar soluciones con impacto de negocio.
- Modalidad remota compatible con Colombia/LATAM o contratación como contractor.

**Evidencia que debe mostrarse:** flujo automatizado, arquitectura simple, manejo de errores, trazabilidad, resultado medible y demo de 60–90 segundos.

## Rol B — AI / Automation Developer

**Prioridad:** secundaria.

**Títulos equivalentes:** AI Developer, Automation Developer, Integration Developer, Full-Stack Automation Developer, LLM Application Developer.

**Problema que resuelve:** productos e integraciones que requieren código además de herramientas low-code.

**Señales de buen encaje:**

- TypeScript/JavaScript, Node.js, APIs REST, PostgreSQL, autenticación, async/await y Docker básico.
- Integración de LLMs, herramientas o agentes en una aplicación real.
- Entorno junior, associate, internship o contractor donde el aprendizaje y la entrega estén explícitos.

**Evidencia que debe mostrarse:** endpoint o webhook funcionando, modelo de datos, autenticación/validación cuando aplique, pruebas básicas y explicación técnica clara.

## Rol C — Implementation / Automation Specialist

**Prioridad:** secundaria, especialmente para agencias y B2B SaaS.

**Títulos equivalentes:** Implementation Specialist, Technical Implementation Specialist, Solutions Consultant, Automation Specialist, Customer Automation Specialist, Technical Onboarding Specialist.

**Problema que resuelve:** implementar y adaptar plataformas para que el cliente obtenga valor rápido.

**Señales de buen encaje:**

- CRM, WhatsApp, Chatwoot, ManyChat, n8n, APIs, soporte técnico o onboarding.
- Contacto con clientes, discovery de procesos, configuración, documentación y capacitación.
- Capacidad de traducir una necesidad de negocio a una automatización funcional.

**Evidencia que debe mostrarse:** antes/después de un proceso, caso de uso por industria, walkthrough breve y comunicación profesional en inglés.

## Restricciones iniciales

- **Geografía:** remoto desde Colombia/LATAM o contratación internacional como contractor.
- **Senioridad:** junior, associate, entry-level, internship o contractor por proyecto. Aplicar a roles mid solo si el alcance y la evidencia encajan de forma extraordinaria.
- **Idioma:** aplicar mientras se mejora inglés; no descartar por requerir trabajo en inglés, pero señalar requisitos C1/C2 como riesgo a revisar.
- **Verdad profesional:** nunca afirmar años de experiencia, métricas, clientes, tecnologías o permisos que no puedan demostrarse.

## No objetivos

- Roles de ML research, data science avanzada o entrenamiento de modelos sin relación con automatización aplicada.
- Vacantes exclusivamente de frontend React o backend senior que no aprovechen el perfil híbrido.
- Puestos que exijan autorización laboral local no disponible y no ofrezcan modalidad remota/contractor.
- Ofertas sin empresa identificable, sin descripción verificable o que exijan pagos del candidato.
