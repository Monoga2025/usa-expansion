# USA Expansion: Career Pipeline and Opportunity Scoring

A small operating system for a relocation and career plan: an opportunity-scoring automation (JSON configs and tests), a SQL schema for tracking opportunities, a job-search qualification rubric, a learning log, and portfolio case-study drafts. Written in Spanish.

## What is included

- `automation/`: ingestion and scoring configuration with a source contract and scoring test notes.
- `db/opportunity-schema.sql`: schema for opportunities and their pipeline stages.
- `career/`: target roles, funnel definition, vacancy validation and a weekly dashboard CSV.
- `learning/`: baseline, interview question bank, weekly routine and progress log.
- `portfolio/`: case-study template and drafts, project inventory and demo scripts.
- `work-and-travel/`: budget and decision notes.

## Stack

- JSON, SQL, CSV and Markdown. No runtime application is included.

## Honest status

- Planning and tracking files. The scoring rules are design specifications and are not connected to live job-board data.
- Personal financial numbers and identity data were not published.
